# 🎵 Spotify Trends Dashboard

## 📌 Project Overview
The **Spotify Trends Dashboard** is an interactive data visualization project designed to analyze and explore music trends using Spotify data. This dashboard provides insights into popular tracks, artists, genres, and audio features to help understand listening patterns and music popularity.

The project focuses on transforming raw Spotify data into meaningful visual insights using **Power BI**, enabling data-driven analysis through charts, filters, and KPIs.

---

## 🎯 Objectives
- Analyze Spotify music trends using real-world data  
- Identify top artists, tracks, and genres  
- Understand audio feature patterns such as energy, danceability, and popularity  
- Create an interactive and user-friendly dashboard  
- Practice data cleaning, modeling, and visualization skills  

---

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard creation and visualization  
- **Spotify Dataset** – Music and audio feature data  
- **Excel / CSV** – Data preprocessing (if applicable)  
- **DAX** – Measures and calculated fields  

---

## 📊 Dashboard Features
- 🎶 **Top Tracks & Artists** – Based on popularity  
- 📈 **Trend Analysis** – Popularity trends across time  
- 🎧 **Audio Features Analysis** – Energy, danceability, valence, tempo  
- 🧑‍🎤 **Genre Insights** – Most popular genres  
- 🔍 **Interactive Filters** – Artist, year, genre, and popularity range  

---

---

## 🚀 How to Use
1. Download or clone this repository  
2. Open `spotify.pbit` using **Power BI Desktop**  
3. Load or refresh the dataset if prompted  
4. Use filters and visuals to explore music trends
